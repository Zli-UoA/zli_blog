## まえがき

筆者の[Tenplant](https://x.com/tenplant1203)です。普段は web を中心に触っています。
今回は[STORES Tech Conf 2026 "World 2"](https://storesinc.tech/conf/2026)に参加させていただきました！初めてのカンファレンスだったので、個人的にとても楽しみにしていました。

## 学生向けランチ会

開会前に学生と STORES 社員の方々とのランチ会がありました。個人的にはここで普段のコミュニティ以外の人と話す機会をいただけてとても嬉しかったです。自分の知らない分野であったり、知っていても深くは触れていなかった分野のお話を聞くことができました。また、先輩と関わりのある方ともお会いすることができ、その時のテーブルでは本を書くことの良さについてお話を聞かせていただきました。

## 発表セッション

特に印象に残っているセッションは`1 人がチームになる、開発組織のフラクタル by kitapashi`でした。聴き入ってしまい、写真を撮ることを失念していました...。

LLM との向き合い方は多くの方が嫌でも考えさせられたことがあると思います。LLM を利用してより早く正確にアウトプットができた。けど LLM をチームの一員として利用するにもプロジェクトマネジメントであったり、ドメインの理解などは人間が担うのでまだまだエンジニアリングは死なないと思っていても、LLM の進化は止まらず、その認識を改めざるを得なくなるなど、一人のエンジニアとして LLM と向き合ってきた様々な経験などの道のりを聴かせていただきました。一人が一つのチームを、一人が複数のチームになるように、これはあくまで[フラクタル](https://ja.wikipedia.org/wiki/%E3%83%95%E3%83%A9%E3%82%AF%E3%82%BF%E3%83%AB)の一片なのかもしれない。重要なのは立ち位置を考え続けること。「あなたならどうしますか？」という結びでセッションは終わりました。

LLM の進化によって手でコードを書いたりすることが少なくなったり、今やレビューもしなくなったという方、大量のコードレビューに頭を悩ませている方など皆さんそれぞれ色々な変化を体験されていると思います。もちろん LLM によってより重要な部分に集中することができるのは素晴らしいことですし、ものづくりという点においては自分もこういうものが欲しいなどを手軽に形にできたり、逆に書くのが面倒な部分を任せられたりするのは嬉しいです。自分は vim で泥臭く手を動かしてものを作っている時間もとても面倒ですが好きなので(もちろん LLM でなにかを作るのも好き)、仕事ではコードを書いたりすることがなくなっても、プライベートでは手書きコーダーとしても遊んでいたいと思いました。

## ポスターセッション

とても内容の濃いポスターがたくさんあり、またセッションの空き時間にポスターを作成された方に直接お話しすることができました。裏話や解説などを聞けてとても面白かったです。特に kuro についてや今後のエンジニアとして LLM との向き合い方や意識などについて、経験豊富なエンジニアとしての貴重な意見をいただきました。

## そのほかのコンテンツ

メインのセッション以外の、わたしが参加させていただいたコンテンツについてご紹介させていただきます。
