## 概要

- Zli の Slack チャンネル (#t_webfront) で持ち上がった読書会企画を、esa での企画書作成と経費申請を経て、公式サポート (書籍代 + 昼食代) 付きのイベントにしました。
- 「事前読書なし・5人限定・1日集中 (60分サイクル)」という進め方で、脱落者なし・全6章を完走しました。
- この前例と学内LTでの共有がきっかけで、「TRPL輪読合宿」や「Three.js勉強会」など次の企画が立ち上がっています。
- 昼食付きの集中輪読会は想像以上に捗りました。

## 1. 企画を公式化するまで

Zli は会津大学の技術系サークルです。サークル内には自由に参加・作成できる Slack チャンネルがあり、その中の #t_webfront で「SOPやCORSなどブラウザのセキュリティモデルを根本から理解したい」という話が出ました。

これを有志の集まりで終わらせるのはもったいない、ということで、サークル公式の支援を取り付ける方向に動きました。

まず esa (文書共有ツール) で [企画書](https://esa-pages.io/p/sharing/14287/posts/345/8002b95de2e70c2948aa.html) を作成・共有しました。目的、開催日時、タイムスケジュール、予算 (書籍代・昼食代) を書いています。

会計との交渉では「1日通して実施する集中型勉強会のため、昼食代の支給が必要」と伝えたところ、書籍代 (1,000円) と昼食代 (上限1,000円/人) の経費支援が認められました。

企画の通し方は決まった形がなく、正直手探りでした。それでも、「目的と計画をきちんと書いて出せば、有志の企画でも公式サポートを受けられる」という前例を作っておきたかった、というのが本音です。

## 2. 当日の進め方

輪読会は長期間になると脱落やモチベーション低下が付きものなので、今回は1日で一気に終わらせる形にしました。

- 日時・場所  
2026年7月20日 (月・海の日) 10:00〜16:20 / あいおいΔ
- 参加人数  
密度を保ち、全員が議論に参加できるよう5名に限定  
[connpass 募集ページ](https://zli.connpass.com/event/400695/)

進行は、当初1章あたり60分を3ステップに分けて回す予定でした。

- 20分 読書
- 20分 担当者による解説
- 20分 参加者全員での議論

実際には時間を厳密に区切らず、担当者が解説しながら議論も進める形式に落ち着きました。

## 3. 技術的な学び

『Origin 解体新書』 (Jxck著) は、ブラウザのセキュリティ構造を低レイヤまで解説してくれます。当日の議論で特に印象に残った話を2つ。

### Origin の定義と CORS の理解

Origin の定義は「scheme / host / port のタプル」。どのプロトコルで、どのホストに、どのポートへアクセスしているか、という話です。最初にこの定義が明確になった時点で、かなりスッキリしました。

CORS の章では、その定義と今まで遭遇してきたエラーがようやく繋がりました。CORS で弾かれるのは、リクエスト自体が送られないからではなく、レスポンスを JavaScript から読めるかどうかをブラウザが判断しているから、というのが大きかったです。この概観が頭に入ると、preflight がなぜあるのかや、ブラウザがなぜ CORS を実装しているのかも自然に納得できました。

### COEP・COOP・CORP: 略語が多すぎる

Chapter 06 (Site Isolation 関連) では、担当者が次の記述を読み上げた瞬間、全員が「えっ」という顔をしていました。

「あるページが COEP と COOP を指定すれば、そのページに含まれる全てのサブリソースは CORP を必須とし、Opener も COOP が一致するページとしか生成されない」  
—— 『Origin 解体新書』 Chapter 06 より

Site Isolation のような複雑な概念は1日では到底消化しきれず、「分かったつもり」で終わってしまった部分もあります。それでもブラウザの内部構造に踏み込む面白さはしっかり体感できたので、今後も勉強を続けていきたいです。

## 4. その後の展開

[開催週の水曜日に行われた学内LT](https://zli.connpass.com/event/400546/) で本勉強会の開催報告を実施し、その後の懇親会で企画書の作成手順や会計交渉の進め方を共有しました。

すると「自分たちも企画を通してサポートを受けよう」という話になり、現在サークル内で動いている企画はこんな感じです。

- TRPL (The Rust Programming Language) 輪読合宿  
「泊まり込みにするなら銭湯代の支援も申請できるのでは」というアイデアから企画化。

- Three.js勉強会  
自然発生的に企画・調整中。

## おわりに

というわけで、1日集中 + 少人数 + 食事つきという組み合わせは、予想以上に効きました。「読みたい本はあるけど輪読会は続かない」と感じている人には、一度試してみる価値があると思います。

企画を公式サポート付きで通すのは初めてで、手続きの進め方も手探りでした。それでも「目的と計画をきちんと書けば話は通る」というのが体感として分かったので、それがいちばんの収穫です。

Zli メンバーで企画の通し方や会計との交渉の話が聞きたい人がいたら、声をかけてもらえれば実際にやった内容をそのまま共有します。
