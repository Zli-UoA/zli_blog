### 初めての合宿形式

今回は Zli では初めての合宿形式での勉強会で、参加者は 7 人でした。
長時間なのでかなり疲れましたが、その分、量の多い内容を扱うことができ、TRPL の 1〜10 章、13 章、17 章、18 章までを **2 日間** (~~最終的に終わったのは三日目の朝 4 時頃~~)で進めることができました。  
まとまった時間を確保して取り組めたことで、各章の内容について普段より深く議論したり、難しい部分をしっかり理解することができました。  
一人だとダラダラ進めてしまいそうな内容を、まとまった時間を取ることで一気に進められたのは勉強会ならではかなと思いますし、合宿形式によって通常の勉強会に比べて多い分量をこなすことができました

## 輪読会の様子

![輪読会の様子](/articles/trpl-workshop-2026/scenes1.webp)

輪読会は以下のように進みました。

- それぞれの章の難易度を見ながら担当を割り当て
- 時間をとって読み込み
- 担当者がその章を解説

私は [「3. 一般的なプログラミングの概念」](https://doc.rust-jp.rs/book-ja/ch03-00-common-programming-concepts.html#一般的なプログラミングの概念)と[「10.1. ジェネリックなデータ型」](https://doc.rust-jp.rs/book-ja/ch10-01-syntax.html#ジェネリックなデータ型)を担当しました。

実際に参加してみると思っていたより大変でしたが、かなり楽しかったです。
理解の怪しい部分や説明が詰まった際は経験者の方々が指摘や補助をしてくれたのでスムーズかつ深い理解を得られました！  
一人で読むのと比べて、自分の理解があやふやな部分を突っ込んでもらえたり、怪しい部分の解説を経験者の方々に聞けたのは良かったです。  
「式と文」の説明をした直後に `if` 式を `if` 文と言ってしまい、早速突っ込まれる場面もありました。  
また、先輩後輩関係なく質問しやすく、経験者の方が一方的に教えるだけではなく、先輩からも「これってどうなの？」という質問によってより深い理解が得られたと思います。

![ホワイトボードを使った解説](/articles/trpl-workshop-2026/scenes2.webp)

特に所有権や借用、ライフタイムやトレイトなど慣れない要素に関してはしっかり時間をとって理解することができました。
一人だとかなり時間がかかってしまったり、挫折してしまいそうな内容でしたが、なんとか進められたのでこういった部分も輪読会の魅力かなと思います。

Rust 特有の概念や思想によって安全性を担保しているのも面白いなと思いました。
特に所有権やライフタイムは Rust ならではの考え方があって面白かったです。

また、今回使用した日本語版 TRPL と現在の Rust では一部仕様が変わっています。
パターンマッチングで `ref` や `ref mut` を使う部分についても、現在では参照をマッチすると暗黙的に参照として束縛されるようになっているという補足がありました。

こういった補足がなければかなり詰まっていたと思うので、経験者の方々と一緒に読めたのはかなり助かりました。

他にも、ライフタイム省略の 3 つの規則や、`FnOnce`, `FnMut`, `Fn` がどういう位置づけになっているのかなど、自分が「ここがわからない」となった部分はその場で質問しながら進めました。

![関数型プログラミングについて脱線している様子](/articles/trpl-workshop-2026/sidetracked.webp)

休憩時間には関数型プログラミングの話になったりと脱線することもありましたが、それも含めて楽しかったです。
休憩や雑談の中からさらに勉強したい部分が出てきたり、興味を深められたりしたのも良かったです。

## 終わりに

今回の輪読会をきっかけに、TRPL を読み直したり、Axum を少し触ってみたりと、その後も Rust の勉強を続けています。
また、輪読会が終わった後も Rust に関する情報共有があるのも良かったです。

ここまで深く Rust を勉強できたので、もっと深く理解してみたいと思うようになり、次の LT で Rust についてやってみようかなと思うきっかけにもなりました。
今では楽しい Rust ライフを送れています。

一人でやると、どうしてもダラダラ進めてしまったり、間違った理解のまま進んでしまったり、一番良くない場合だと挫折してしまう可能性もあったと思います。
そういった部分が今回の輪読会で解消されたのは、輪読会ならではだったと思いますし、経験者の方々のご尽力のおかげだなと思いました。

また、丁寧に教えてくださった複数人の経験者の皆様、ありがとうございました！
